# 🤖 AI FAQ Chatbot

AI FAQ Chatbot is a simple and interactive web application that provides instant answers to **Frequently Asked Questions (FAQs)** through a chatbot-style interface.

The application helps users quickly find answers without manually searching through a list of questions.

## ✨ Features

* 🤖 Interactive chatbot interface
* 💬 User and chatbot message bubbles
* ❓ Frequently Asked Questions (FAQ) knowledge base
* 🔍 Question matching and answer generation
* 💡 Suggested questions
* ⏳ Typing/loading animation
* 🕒 Message timestamps
* 🗑️ Clear chat functionality
* ⌨️ Press Enter to send messages
* 📱 Responsive and mobile-friendly design
* ⚠️ Friendly response for unknown questions

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run

1. Clone or download this repository.

2. Open the project folder.

3. Open `index.html` in any modern web browser.

4. Type a question in the chatbot input box.

5. Click **Send** or press **Enter**.

6. The chatbot will provide the most relevant answer from the FAQ knowledge base.

## 💡 Example Questions

**User:** What courses are available?

**Chatbot:** The available courses are displayed based on the college FAQ information.

**User:** When are the exams?

**Chatbot:** The chatbot provides the exam-related information available in its FAQ knowledge base.

## ⚙️ How It Works

1. The user enters a question.
2. JavaScript processes the question.
3. The application compares the question with the available FAQ data.
4. The most relevant answer is displayed.
5. If no matching question is found, the chatbot displays a helpful fallback message.
